
# Task Manager

A small, responsive task manager built with React and Vite. This project demonstrates a minimal React setup with a lightweight UI for adding, completing, and deleting tasks.

## Features

- Add tasks with the input or press Enter
- Mark tasks as complete / undo
- Delete tasks


## Quick start

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the dev server:

   ```bash
   npm run dev
   ```

3. Open the app in your browser at the local URL reported by Vite (e.g. `http://localhost:5174/`).

## Scripts

- `npm run dev` — start development server with HMR
- `npm run build` — build for production
- `npm run preview` — preview production build locally


## Notes & suggestions

- Tasks are persisted to `localStorage` in the browser. Data will remain between sessions on the same machine and browser.
- Consider adding TypeScript and testing for larger projects.
